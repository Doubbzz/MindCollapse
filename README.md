# MindCollapse
A psychological 2D narrative game exploring the mind’s collapse.

## Getting started

1. Install [Godot Engine 4.0 or newer](https://godotengine.org/download).
2. Open Godot and choose **Import** → select the `project.godot` file located at the root of this repository.
3. Once the project loads, press <kbd>F5</kbd> (or click **Play**) to experience **Mental Breakdown — Chapter 1: "The Beginning of the End"**.

### Controls

* <kbd>WASD</kbd> / Arrow keys — move the character within the room.
* Mouse — navigate the menu UI.

### Assets

To keep the repository text-only and friendly for platforms that disallow large binaries, the project now uses simple gradients and procedurally generated audio defined directly in the scene files. You can drop your own art or sound effects inside the `assets/` folders and update the scenes if you want custom production values.
